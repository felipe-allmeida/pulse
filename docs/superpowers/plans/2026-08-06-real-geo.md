# Real Visitor Geolocation (DB-IP Lite) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show real visitor locations on the live map in production by making the true client IP survive the NPM → Caddy → API proxy chain and pointing the (unchanged) geo locator at a free local DB-IP Lite database, with a CC-BY attribution.

**Architecture:** Backend `ForwardedHeaders` reconfigured (trust the two private proxy hops, `ForwardLimit=2`) so `RemoteIpAddress` is the real visitor; Caddy `trusted_proxies` so it forwards the visitor's `X-Forwarded-For`; the existing `GeoLocator` reads DB-IP Lite's MMDB unchanged (selected in prod via `Geo:DbPath` + `Geo:DemoFallback=false`); a localized "IP data by DB-IP" attribution; the DB is mounted via Portainer (documented, never committed).

**Tech Stack:** .NET 10 minimal API + `ForwardedHeaders` + xUnit/WebApplicationFactory; Caddy; React 19 + Vite + react-i18next; Docker/Portainer compose.

## Global Constraints

- **TS strict, no `any`; C# nullable-aware.** English + pt-BR (attribution localized via existing i18n).
- **The geo DB is never committed** (licensed). No geo-resolution logic change. The demo fallback stays for local/no-DB.
- **Privacy:** IP resolved locally, never stored; `VisitStarted` still carries no IP.
- **Hard gate every task:** relevant subset of `dotnet build` + `dotnet test` (check `pgrep -f "dotnet test"` first — shared machine) and `pnpm -C web build` + `pnpm -C web exec tsc --noEmit` + `pnpm -C web test`, all green.
- Correctness of the IP fix is proven by an integration test, not by prose.

```csharp
builder.Services.Configure<ForwardedHeadersOptions>(o =>
{
    o.ForwardedHeaders = ForwardedHeaders.XForwardedFor | ForwardedHeaders.XForwardedProto;
    o.ForwardLimit = 2; // NPM -> Caddy -> API
    o.KnownNetworks.Clear();
    o.KnownProxies.Clear();
    o.KnownNetworks.Add(new IPNetwork(IPAddress.Parse("10.0.0.0"), 8));
    o.KnownNetworks.Add(new IPNetwork(IPAddress.Parse("172.16.0.0"), 12));
    o.KnownNetworks.Add(new IPNetwork(IPAddress.Parse("192.168.0.0"), 16));
});
```
